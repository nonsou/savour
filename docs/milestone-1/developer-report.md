## Production build guard (round 4)

* Why: Vercel auto-targeted the first deployment at Production despite `--target preview`. Sol
  removed both deployments (zero remain) and further cloud deployment waits for owner approval.
* What: `saas/scripts/build-guard.mjs`, run by `npm run build` before `next build` and again inside
  `next.config.ts` during the production-build phase. It refuses `VERCEL_ENV`/`VERCEL_TARGET_ENV` =
  production, and any Vercel build whose environment is missing or not `preview`. It allows local
  builds and Vercel Preview.
* Tests: `tests/unit/build-guard.test.ts`, 16 tests. They spawn the real script for 4 allowed and 8
  refused environments (exit codes and messages), run `npm run build` with Vercel Production (it fails
  at the guard before Next.js starts), check the package script wiring, and check the `next.config`
  layer (throws for the production build phase, not for dev; returns the config for Preview).
* Not done by the developer: no production build (Sol runs it), no cloud changes, commit or push.

## Mobile table readability (round 5)

* Cause: `.card { overflow-wrap: anywhere }` was inherited by table cells, so each column could
  shrink to one character. Tables never overflowed their wrapper, so headings wrapped every 2–4
  letters at 390px (Sol's `/tmp/savour-qa/mobile-overview.jpg`).
* Fix (CSS only, plus one class): headings no longer wrap; cells inside `.table-wrap` get minimum
  widths (first column 9rem, others 5rem) and wrap between words; long free text goes in
  `td.wide` (review response column, 14–28rem, breaks long unbroken text). `.table-wrap` scrolls
  sideways inside its card.
* Check: headless Chrome rendered a static fixture (real `globals.css`, the same table markup,
  Yoruba names, a long unbroken note) at 390px (`/tmp/savour-qa/table-fixture-390.png`). Document
  width was 390, so the page does not scroll sideways. The overview table scrolls in its wrapper
  (728 px content in a 356 px wrapper), as do the report subjects table (693/356) and the review
  table (552/324). The 3-column assessor table fits with no scroll. All headings are a single line.
  This is a fixture check, not a signed-in run of the real pages.
